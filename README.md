# Agent skills

Private, sanitized Codex skills for maintainable agentic engineering work.

| Skill | Purpose |
| --- | --- |
| `entity-cleanup` | Decide whether a code artifact, module, file, or mechanism should be kept, warned about, archived, or removed. |
| `shared-resource-leases` | Coordinate cooperative agents using health-aware, time-bounded leases for shared local resources. |
| `whiteboard-mental-model` | Explain complex systems as a causal model without confusing authority, runtime, evidence, and consumers. |

These versions intentionally contain no organization-specific names, paths,
resource identifiers, credentials, customer information, or infrastructure
topology. They are reusable patterns, not copies of an internal environment.
